# Impeccable Design Standards

Whenever modifying, auditing, or adding UI/UX components, web layouts, or styles in this repository:

1. **Adhere to the Skill Directives:** Follow the comprehensive directives and playbooks located in [.agents/skills/impeccable/SKILL.md](file:///d:/PROJECTS/Distributed%20Flash%20Sale%20Engine/.agents/skills/impeccable/SKILL.md) and [.agents/skills/impeccable/reference/](file:///d:/PROJECTS/Distributed%20Flash%20Sale%20Engine/.agents/skills/impeccable/reference/).
2. **Respect Design Truth:** All visual tokens, color systems, typography scales, and motion patterns must align with [DESIGN.md](file:///d:/PROJECTS/Distributed%20Flash%20Sale%20Engine/DESIGN.md) and [PRODUCT.md](file:///d:/PROJECTS/Distributed%20Flash%20Sale%20Engine/PRODUCT.md).
3. **Audit & Detect:** Regularly run `impeccable detect` to verify 0 anti-patterns, maintain minimum 44px touch targets on interactive controls, guarantee `prefers-reduced-motion` compliance, and preserve high accessible contrast.
4. **Preserve Copy & World:** Refinements must preserve existing textual copy, headings, and data streams while elevating visual hierarchy and layout precision.
